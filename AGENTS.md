# Instruções do projeto

## Git e entrega

- Depois de concluir e validar uma alteração solicitada pelo usuário, crie um commit e faça push automaticamente para a branch e o remoto atuais.
- Inclua no commit somente os arquivos relacionados ao trabalho solicitado e preserve alterações não relacionadas.
- Não faça commit ou push quando o usuário pedir explicitamente para não fazer.
- Nunca versione segredos, credenciais, arquivos `.env` ou dados sensíveis.
- Se o commit ou o push falhar, informe o erro claramente e deixe o estado local recuperável.
